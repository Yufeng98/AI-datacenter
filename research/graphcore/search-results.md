## Key Findings (Quick Reference)

### Hardware
- **IPU generations:** Mk1 (2018), GC200 Colossus Mk2 (2020), Bow IPU (2022, TSMC 7nm WoW)
- **Tiles per chip:** 1,472 (each is an independent MIMD processor)
- **Threads per tile:** 6 hardware worker + 1 supervisor = 7 contexts; 8,832 total threads on GC200
- **In-Processor Memory (SRAM):** 900 MB per chip (624 KB/tile)
- **Compute:** 250 TFLOPS (FP16, GC200) / 350 TFLOPS (Bow IPU)
- **Process:** TSMC 7nm; Bow uses 3D wafer-on-wafer for power delivery
- **Clock:** 1.85 GHz (Bow) vs 1.35 GHz (Mk2)
- **Exchange bandwidth (on-chip):** 11 TiB/s all-to-all
- **Streaming Memory:** DDR4 DIMMs, up to 112 GB/IPU, 180 TB/s aggregate (M2000)

### Execution Model
- **BSP (Bulk Synchronous Parallel):** alternates compute phase → exchange phase → barrier sync
- **MIMD:** each tile runs independent instruction stream (vs GPU SIMT)
- **No caches:** deterministic memory latency via private SRAM per tile

### Software Stack
- **Poplar SDK** (latest: 3.4.0, March 2024): graph-based compiler and runtime
- **PopLibs:** built-in op libraries (BLAS, convolutions, normalizations, reductions)
- **PopART:** ONNX-based training/inference runtime
- **PopTorch:** PyTorch extension for IPU (wraps Poplar compiler)
- **TF2/TF1 for IPU:** TensorFlow backends targeting Poplar
- **Codelets/vertices:** C++ or assembly kernels compiled per tile
- **PopVision:** profiling/analysis tools

### Interconnect
- **IPU-Link:** direct IPU-to-IPU links within an IPU-Machine (M2000)
- **GW-Link:** gateway links between racks (looped or switched topology)
- **IPU-POD systems:** POD4, POD16, POD64, POD128, POD256, up to 64K IPUs (~16 exaFLOPS)

### Acquisition (July 2024)
- Acquired by SoftBank for ~$500M — ⚠️ *hedged 2026-08-08: terms were never officially disclosed; reported at roughly $500–600M (Sifted "$600m+", Jon Peddie Research "$500–600 million"). Treat "~$500M" as an estimate.*
- Operates as SoftBank subsidiary under Graphcore name
- Aligned with SoftBank's Arm holdings and ASI vision
- SDK 3.4.0 (March 2024) was last major release; next-gen product timeline unclear
