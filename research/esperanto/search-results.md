## Key Facts Extracted

### Chip Identity
- **Full name**: Esperanto ET-SoC-1 (ET-SoC = Esperanto Technology System-on-Chip)
- **Announced**: Hot Chips 33, August 2021; silicon available Q1 2022
- **Process**: TSMC 7nm
- **Transistors**: 24+ billion
- **Die area**: 570 mm²
- **Mask layers**: 89

### Compute Core Configuration
- **1,088 ET-Minion cores**: in-order, 64-bit RISC-V RV64GCV compatible, each with vector/tensor unit
- **4 ET-Maxion cores**: out-of-order, quad-issue, 64-bit RISC-V, for OS/host tasks
- **ET-Minion peak**: 128 INT8 GOPS per GHz per core
- **Chip peak**: 100–200 TOPS (frequency-dependent)
- **Power**: < 20W TDP

### Memory
- **On-chip SRAM**: >160 MB (160 million bytes)
- **Off-chip DRAM**: LPDDR4x controllers, up to 32 GB per chip
- **Storage**: eMMC Flash interface
- **Host interface**: PCIe Gen4 x8

### Scale-up
- **Glacier Point v2 card**: 6 ET-SoC-1 chips
- **Card totals**: 6,558 RISC-V cores, 192 GB DRAM, 822 GB/s DRAM bandwidth

### Software Stack
- **ML compiler**: Based on Meta's Glow open-source compiler
- **Input formats**: PyTorch (via ONNX export), ONNX native, TensorFlow (via ONNX)
- **Runtime**: Custom ONNXRuntime backend with ET-SoC-1 execution provider
- **SDKs**: Primo AI/ML SDK (inference), General Purpose SDK (HPC/C/C++, May 2023)
- **Programming model**: Standard C/C++ directly on 1,000+ RISC-V cores; massively parallel SPMD-style

### Corporate Timeline
- **2017**: Founded by Dave Ditzel (former Intel, Transmeta, SiFive)
- **Aug 2021**: HC33 unveil
- **Apr 2022**: Silicon in customer hands; Samsung SDS evaluation
- **May 2023**: General Purpose SDK (HPC/C/C++) launched
- **Nov 2024**: NEC HPC partnership; ET-SoC-2x/3x roadmap previewed
- **Jul 2025**: Esperanto Technologies closes (staff attrition)
- **2025-10-22**: Ainekko launches "AI Foundry" — a *separate* event from the acquisition *(corrected 2026-08-08; the earlier entry "Oct 2025: Ainekko acquires all IP" conflated the two)*
- **2025-11-19**: Ainekko announces acquisition of all Esperanto IP (chip designs, software, tooling); release describes "more than 1,000 Minion™ cores on a single die", names no license, says only "exploring foundation-based governance"
- **2026-01-29**: Ainekko merges with MRAM startup Veevx *(corrected 2026-08-08 from "Nov 2025")*
- **2026-04-20**: `openhwgroup/core-et` and `core-et-erbium` repos created — the code becomes public *(corrected 2026-08-08 from "Nov 2025 open-sourced")*
- **2026-05-05**: Manifesto "The Next Thousand Chips" (nekko.ai only)
- **2026-06-02**: "CORE-ET Silicon Platform (ETSP)" accepted as an OpenHW Foundation project; 16nm tapeout in progress; NoC with integrated MRAM
