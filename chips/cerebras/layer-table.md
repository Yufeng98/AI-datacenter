# Cerebras WSE-3 — Software Stack Layer Table

*as_of: 2026-08-08*
*device_class: Wafer-Scale Engine*
*chip: cerebras (WSE-3 / CS-3) — no WSE-4 / CS-4 announced as of 2026-08-08*

| Layer | Component | Key Details | Open? | Notes |
|---|---|---|---|---|
| **Framework Integration** | cerebras.pytorch (cstorch) | PyTorch 2.0 Lazy Tensor Core (LTC) backend; `cstorch.compile(model, backend="CSX")`; `cstorch.Trainer` for training lifecycle | SDK release | Replaced XLA in release 2.0; tracks upstream PyTorch |
| **Framework Integration** | Trainer + YAML config | Primary production training interface: YAML file specifies model/dataset/optimizer/lr_scheduler/callbacks; `cstorch.Trainer` instantiates and manages compile/run/checkpoint lifecycle; recommended path for LLM training | SDK release | Most Model Zoo configs use YAML Trainer; zero WSE-specific code needed |
| **Framework Integration** | Cerebras Model Zoo | github.com/Cerebras/modelzoo; Llama 2/3, GPT-2/3, Mistral, Mixtral, BERT, T5, DINOv2, LLaVA; YAML-driven Trainer configs | Open source (Apache 2.0) | 40+ model configurations; HF checkpoint conversion |
| **Framework Integration** | PyTorch Sparsity Library | GMP + SRigL unstructured sparse training; integrated into cstorch training loop | SDK release | Gradient-magnitude and sparse RigL algorithms |
| **Compiler / IR** | CIRH (Cerebras IR — High) | MLIR-based ATen-aligned IR; operator fusion (FlashAttn, LayerNorm+dropout, GeLU+proj); constant folding; memory layout optimization; AutoGen kernel generation | Closed | Not user-visible; executes mode selection: Layer Pipelined vs Weight Streaming |
| **Compiler / IR** | AutoGen | Automatic CSL kernel generation from CIRH op patterns; eliminates manual CSL for standard training ops | Closed | Active for matmul, attention, normalization; custom ops require manual CSL |
| **Compiler / IR** | Compile Report | Per-layer utilization, memory usage, throughput projections; Incremental Compile for unchanged graphs | SDK toolchain | Key for diagnosing model performance before long training runs |
| **Op Library** | Fused Op Library (via CIRH) | FlashAttention-style fusion, fused LayerNorm+dropout, fused GeLU+linear; implemented as CIRH graph rewrites | Closed | Fusion patterns applied automatically during compilation |
| **Op Library** | Model Zoo ops | Layer implementations for Llama MHA, Mixtral MoE, DINOv2 ViT, LLaVA cross-modal; operator-level configs | Open source | Specific model-optimized op configs tuned for WSE-3 PE layout |
| **Kernel Library** | CSL (Cerebras Software Language) | Zig-inspired low-level PE kernel language; dataflow model: Tasks activated by wavelet arrival on Colors; DSDs for SRAM addressing; compile-time metaprogramming | Public SDK | sdk.cerebras.net; sdk-examples open source; replaces CUDA/PTX for WSE |
| **Kernel Library** | CSL Standard Libraries | `<collectives_2d>`: reduce/broadcast/scatter-gather across 2D mesh; `<message_passing>` (WSE-3): explicit PE-to-PE point-to-point; `<math>`, `<time>`, `<io>` | Public SDK | Built-in CSL libraries; not user-extensible |
| **Kernel Library** | SDK Examples | github.com/Cerebras/sdk-examples; GEMM, stencils (1D/2D/3D), stochastic rounding, custom scientific ops | Open source | Reference CSL implementations for scientific computing |
| **Runtime** | SdkRuntime API | Host Python/C++ API: compile, load, launch CSL binary; symbol I/O; memcpy h2d/d2h; controls CS-3 device | SDK | Primary runtime API for SDK path |
| **Runtime** | Appliance API | CS-3 multi-job appliance mode: device allocation, program lifecycle, concurrent job management | SDK | Production datacenter deployment interface |
| **Runtime** | MemDataLoader | Cerebras-specific data pipeline: prefetch batches; stream formatted data into PE memory; replaces PyTorch DataLoader | SDK | Required for all training on CS-3 |
| **Runtime** | Weight Streaming Scheduler | Coordinates layer weight dispatch: MemoryX → SwarmX → CS-3 PE SRAM; prefetches next layer while computing current | Closed | Core runtime component for weight streaming mode |
| **Driver / Firmware** | csctl CLI | Job submission, queue management, device status; Grafana dashboard integration; Slurm scheduler hooks | SDK | Production job management for CS-3 clusters |
| **Driver / Firmware** | Compile Server | Dedicated host for CIRH→PE binary compilation (separate from inference/training host) | Closed | Compilation is compute-intensive; runs on host CPU cluster |
| **Communication** | cerebras.pytorch.distributed | Multi-replica data-parallel training API; gradient all-reduce semantics over SwarmX; similar interface to torch.distributed | SDK | Primary distributed training API for PyTorch path |
| **Communication** | CSL `<collectives_2d>` | On-chip collective library: reduce/broadcast/scatter across 2D PE mesh using Swarm wavelet routing | Public SDK | Used inside CSL kernels; no software switching overhead |
| **Communication** | CSL `<message_passing>` | Point-to-point PE messaging library (WSE-3 only): explicit send/recv between arbitrary PEs; new in WSE-3 | Public SDK | Enables custom communication patterns beyond collectives |
| **Communication** | SwarmX Fabric | 100GbE physical + proprietary low-latency protocol + RoCE RDMA; tree topology; up to 2,048 CS-3s; broadcast weights / reduce gradients | Proprietary HW | No user API; transparent to cerebras.pytorch.distributed users |
| **Assembler / ISA** | CSL Language (micro-ISA) | Wavelet = 32-bit data+color-tag message; Color = virtual channel (0–23 per PE); Task = wavelet-activated handler; DSD = typed SRAM view | Public SDK | Serves as the ISA abstraction for PE programming |
| **Assembler / ISA** | Data Structure Descriptors (DSDs) | Typed, strided memory views over PE-local 48KB SRAM; 1D/2D/4D access patterns; stride and extent fields | Public SDK | Replaces raw pointer arithmetic in SRAM; all SRAM access via DSDs |
| **Compute Engine** | 900K PE Array | 900,000 PEs; 8-wide FP16/BF16 SIMD; 16-wide INT8 SIMD; FP32; own PC per PE; 0.05mm² per PE | Proprietary HW | No SIMT/warp model; each PE executes independently |
| **Data Path** | Swarm 2D Mesh | Hardware 5-port router per PE; 24 colors; 32-bit wavelet messages; ~1 ns/hop; 100 Pb/s aggregate; <1 pJ/bit | Proprietary HW | On-wafer fabric; replaces NVLink for intra-chip communication |
| **On-chip Memory** | 44 GB On-chip SRAM | 48 KB per PE × 900K PEs = 44 GB total; single-cycle access; 21 PB/s aggregate bandwidth; no HBM | Proprietary HW | PE-private; no coherence protocol; addressed via DSDs |
| **Off-chip Memory** | MemoryX | DRAM+Flash tiers; SKUs: 4TB, 24TB, 36TB (enterprise), 120TB, 1.2PB (hyperscale); weight-only; no activation storage | Proprietary HW | Elastic capacity; prefetch scheduler hides weight transfer latency |
| **Host Interface / Package** | CS-3 System Package | PCIe host interface; custom 300mm wafer PCB substrate (TSMC cross-scribe-line metal); water-cooling cold plate; ~mini-fridge form factor; ~23 kW TDP; wafer die area **46,225 mm²** (corrected 2026-08-08 from 46,255) | Proprietary HW | TSMC custom packaging process developed by Cerebras; CS-3 assembly capacity being scaled ~7× through 2026 via Flex Milpitas lines (2026-07-09) |
| **Scale-up Interconnect** | Swarm 2D Mesh | 100 Pb/s aggregate; <1 pJ/bit; ~1 ns/hop; hardware router per PE; single-word active messages; no software overhead | Proprietary HW | All 900K cores on one wafer = intra-chip; replaces NVLink |
| **Scale-out Interconnect** | SwarmX | 100GbE + RoCE RDMA; tree topology; broadcast weights from MemoryX to all CS-3s; reduce gradients from all CS-3s; up to 2,048 CS-3s | Proprietary HW | Pure data parallelism; no model/tensor parallelism across CS-3s |
| **Scale-out Interconnect** | AMD Helios prefill tier + WSE decode tier *(announced 2026-07-23)* | Disaggregated inference: AMD Helios rack-scale (Instinct) performs prefill / long-context processing, WSE performs decode / token generation; tier-to-tier interconnect and KV handoff mechanism **not disclosed**; vendor-modelled "up to 5× tokens/s/W" (footnote measures TPS/kW vs a Cerebras-WSE-only baseline) | Proprietary HW (AMD + Cerebras) | **Announced only** — expected via Cerebras Cloud in H2 2026; not sampling, not shipping. First break in the "CS-3 is self-contained" framing |
| **Runtime** | Disaggregated prefill/decode serving *(announced 2026-07-23)* | Serving path that routes prefill to AMD Helios and decode to the WSE; exposed initially through Cerebras Cloud | **not disclosed** | No SDK, API surface, scheduler, or placement policy has been published; watch inference-docs.cerebras.ai in H2 2026 |
