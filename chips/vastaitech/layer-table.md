# VastaiTech (瀚博半导体) Layer Mapping Table

*as_of: 2026-08-08*
*chip: vastaitech*
*device_class: GPU-like Inference Accelerator + Video Codec (China, 瀚博 VastaiTech)*

> **Scope:** datacenter PCIe cards only — VA1, VA10, VA1V, VA1L, VA12, VA16, VA10L, and the 南禺/Nanyu VG-series. VE1S / VE1M / VE1V / VS1000 are edge parts and are out of scope.
>
> **Two runtime paths that share nothing above the driver.** Rows below are tagged **[Build_In]** (AOT-compiled, VAMC → VastStream/VastStreamX) or **[vLLM]** (`torch_vacc` + `vllm_vacc`, eager only) where the distinction matters.
